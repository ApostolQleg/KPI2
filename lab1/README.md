# Labortory work №1

## SchemaPostol

## Project description:
- A web-based platform for [Minecraft](https://www.minecraft.net/en-us) players who like to build and want to share their creations for free in a format that is convenient for other palyers.

## Business logic:
#### User
- any visitor can search, filter and view building schematics;
- visitors can download schematic [litematica](https://modrinth.com/mod/litematica) files and [Minecraft](https://www.minecraft.net/en-us) worlds (`.zip`);
- when authorised, user can post his own schemas, manage them and edit some info on his profile;
- when authorised, user can leave comments under schemas;

#### Schema
- schema must have corresponding free, downloadable [litematica](https://modrinth.com/mod/litematica) file loaded;
- schema can have corresponding free, downloadable [Minecraft](https://www.minecraft.net/en-us) world file loaded;
- schemas must have corresponding comment sections;
