# University Laboratory Works

This repository contains the source code for the laboratory works completed during my studies at the Kyiv Polytechnic Institute (KPI).

## Project: **SchemaPostol**

### Domain Overview
- A web-based platform for [Minecraft](https://www.minecraft.net/en-us) players who like to build and want to share their creations for free in a format that is convenient for other palyers.

### System Scope
**Searching**:
   * Search and filter schematics by categories, tags, and Minecraft versions.
   * Free public access to view schematics.
**Schematics**:
   * While uploading, you must attach [.litematica](https://modrinth.com/mod/litematica) schematic files.
   * Optional attachment of full Minecraft world archives (`.zip`).
**Services**:
   * User registration and profile management.
   * Authoring, editing, and deleting owned schematic publications.
   * Saving liked schematics and following liked authors.
**Feedback**:
   * Comment section under each schematic publication.
